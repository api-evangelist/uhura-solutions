# Uhura Solutions

> Uhura Solutions is a London-based AI platform for document-driven process automation in financial services. It combines fine-tuned large language models, a low-code framework, and a visual workflow engine to deliver intelligent data capture, intelligent document processing, and intelligent process automation for banks and financial institutions including Barclays, Raiffeisen, and Erste Bank. Backed by Techstars.

Uhura Solutions publishes no public developer portal, API documentation, or
self-serve API surface as of 2026-07-21. DNS records exist for
api.uhurasolutions.com and docs.uhurasolutions.com but neither host is
publicly reachable — platform access is arranged through sales contact.
